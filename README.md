# Diffraction Simulation

Физический симулятор дифракции Фраунгофера и Френеля.

## Возможности

- **Типы апертур**: одиночная/двойная щель, круглое, прямоугольное, треугольное отверстия, дифракционная решётка, 2 прямоугольных/круглых отверстия, пользовательская
- **Режимы**: дифракция Фраунгофера и Френеля
- **Визуализация**: 2D/3D графики интенсивности, фазы, апертуры
- **Пресеты**: готовые примеры для лабораторных работ

## Зависимости

```
numpy
matplotlib
scipy
streamlit         # для веб-версии
```

## Запуск

**Веб-версия**:
```bash
streamlit run diffraction_task_web.py
```

**Desktop-версия** (только базовый функционал и апертуры, legacy версия):
```bash
python diffraction_task_app.py
```
